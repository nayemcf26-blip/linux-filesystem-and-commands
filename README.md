## 📂 Linux File System

Linux uses a hierarchical file system that starts from the **Root Directory `/`**.

### 🌳 File System Structure

```text
/
├── bin      → Essential user commands
├── boot     → Boot-related files
├── dev      → Device files
├── etc      → System configuration files
├── home     → User personal files
├── root     → Root user's home directory
├── tmp      → Temporary files
├── usr      → Applications and system programs
├── var      → Variable data and logs
└── proc     → Process and system information

💻 Important Linux Commands
🧭 Navigation Commands
pwd
Shows the current working directory.
pwd
ls
Lists files and directories.
ls
ls -la
ls -lh
cd
Changes the current directory.
cd /home
Go back:
cd ..
📁 File & Directory Commands
mkdir
Creates a new directory.
mkdir cybersecurity
touch
Creates a new file.
touch notes.txt
cp
Copies files.
cp notes.txt backup.txt
mv
Moves or renames files.
mv notes.txt linux-notes.txt
rm
Removes files.
rm notes.txt
⚠️ Be careful when using rm.
🔍 File Reading & Searching
cat
Displays file contents.
cat notes.txt
less
Reads a file page by page.
less notes.txt
grep
Searches for text inside files.
grep "linux" notes.txt
find
Searches for files and directories.
find /home -name "notes.txt"
🔐 System & Security Commands
whoami
Shows the current user.
whoami
id
Shows user and group information.
id
ps
Shows running processes.
ps
chmod
Changes file permissions.
chmod 644 notes.txt
df
Shows disk space usage.
df -h
🧪 Practical Example
Create a simple Cyber Security practice directory:
mkdir cyber-lab
cd cyber-lab
touch notes.txt
echo "Linux Cyber Security Practice" > notes.txt
cat notes.txt
Output:
Linux Cyber Security Practice
```
